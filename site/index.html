A hairpin must keep its distance from neighbouring conductors, respect the minimum bend radius, fit the installation space and be insertable basket by basket. A short conductor is only of value if all of these requirements are met at the same time.

Two modules

From the best shape to a pin that can be made.

Module 1

Hairpin generation

Finds the shortest end-winding shape that meets every requirement. Machine learning, verified in CAD.

  • Bayesian optimization of the 3D conductor
  • Clearance, bend radius, installation space, insertion sequence
  • Complete stator, basket by basket
Open the appHow it works

Module 2

Manufacturing

Turns the optimized pin into a bend program and shows what the wire goes through, including springback.

  • Bend program from the 3D centreline: feed, twist, plane, bend
  • Stress-strain curve and springback, live with the material
  • 0.9 to 1.2 mm from the target curve with 20 bends
Open the appHow it works

Both modules use the same pin. Material and machine values in the manufacturing module are assumptions, not measured machine data.
